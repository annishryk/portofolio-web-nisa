# {Annisa Haryoko}. — Portfolio

Personal portfolio website of **Annisa Haryoko**: Application Development at an IBM Silver Partner, web developer and UI/UX designer based in Bogor, Indonesia.

**Live site:** https://annishryk.github.io/portofolio-web-nisa/

## Overview

A single-page portfolio built with plain HTML, CSS and JavaScript, with no framework and no build step. It presents experience, selected projects, skills, education, certifications and publications.

### Highlights

- Sticky sidebar navigation that highlights the section you are reading
- Light and dark theme that remembers your choice
- Typewriter headline and live Jakarta (WIB) clock
- Project cards with a cursor-following spotlight
- Responsive layout, keyboard-friendly and respects `prefers-reduced-motion`

## Tech stack

HTML5 · CSS3 (custom properties, grid, `color-mix`) · Vanilla JavaScript · Google Fonts (Bricolage Grotesque, Instrument Sans, JetBrains Mono)
